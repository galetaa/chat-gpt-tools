# ChatGPT Tools for Safari

Safari Web Extension для ускорения длинных диалогов ChatGPT и локального экспорта бесед. Версия 2.0.2 объединяет оптимизатор исходного `chat-gpt-light` и полезные возможности добавленного ChatGPT Exporter 6.10.0 в одном расширении и одном интерфейсе.

Оптимизатор локально перехватывает JSON активной беседы ChatGPT и передаёт интерфейсу только последние N видимых групп сообщений. Если текущая версия ChatGPT присылает историю прямо в начальном HTML без отдельного conversation-запроса, включается обратимый DOM-fallback: старые turns остаются в документе для экспорта, но исключаются из layout и paint Safari. Экспортёр умеет отдельно прочитать полную загруженную ветку, выбрать нужные сообщения и сохранить их в Markdown, TXT, JSON, CSV или PDF. Данные беседы не отправляются на сторонние серверы.

По умолчанию ползунок использует практичный диапазон 1–20. Точное значение можно ввести в числовое поле рядом. Переключатель `Extended range` расширяет оба элемента управления до 1–100. Старые сохранённые значения выше 20 автоматически сохраняются в расширенном режиме.

Кнопка `Export Conversation` открывает боковую панель непосредственно в ChatGPT. Доступны массовый и индивидуальный выбор, Shift-диапазоны, фильтры prompt/response, reasoning и источники, компактные двухстрочные превью, сохранение настроек и перемещение/изменение ширины панели. PDF создаётся системной печатью Safari: выберите `Save as PDF` в стандартном диалоге macOS.

## Приватность

- Расширение имеет только разрешение `storage` и доступ к двум адресам ChatGPT.
- Нет аналитики, рекламы, удалённой конфигурации, аккаунта расширения или обращений к `chatgptexporter.com`.
- Markdown, TXT, JSON и CSV формируются в текущей вкладке; PDF готовится на локальной extension-странице.
- Временная PDF-задача удаляется из локального хранилища сразу после открытия print preview.

## Требования

- Safari 18 или новее на macOS, iOS или iPadOS.
- Полная версия Xcode для создания приложения-контейнера Safari Web Extension.
- Доступ расширения к `chatgpt.com` (Safari попросит разрешение при первом использовании).

Минимум Safari 18 выбран осознанно: версия использует `content_scripts[].world = "MAIN"`, чтобы установить перехватчик `fetch` до скриптов ChatGPT и не зависеть от CSP страницы.

## Структура

- `Extension/` — готовые web-ресурсы расширения для упаковщика Safari.
- `Extension/scripts/page-script.js` — перехватчик `fetch` в контексте страницы.
- `Extension/scripts/trim-core.js` — проверяемая логика обрезки дерева беседы.
- `Extension/content/dom-trimmer.js` — безопасный fallback для бесед, встроенных ChatGPT в начальный HTML.
- `Extension/content/` — изолированный скрипт Safari, статус и сворачивание сообщений.
- `Extension/content/exporter-core.js` — извлечение полной активной ветки и сериализация локальных форматов.
- `Extension/content/exporter.js` / `exporter.css` — панель выбора и экспорта в стиле macOS.
- `Extension/print/` — безопасный локальный PDF/print preview.
- `Extension/popup/` — интерфейс кнопки расширения.
- `Design/chat-gpt-tools-icon.svg` — редактируемый мастер иконки; PNG-размеры находятся в `Extension/icons/`.
- `package-safari.sh` — создаёт Xcode-проект после установки полной версии Xcode.
- `PORTING_NOTES.md` — подробный разбор отличий, рисков и принятых решений.
- `EXPORTER_PORTING_NOTES.md` — аудит ChatGPT Exporter 6.10.0 и матрица перенесённых возможностей.
- `PERFORMANCE_RESEARCH.md` — проверенные подходы к ускорению и причины, по которым рискованные хаки не включены.
- `CHANGELOG.md` — история пользовательских изменений по версиям.

## Статическая проверка

Она не открывает Safari и не обращается к ChatGPT:

```sh
cd /Users/mac/Documents/dev/chat-gpt-tools
npm run verify
```

## Быстрый тест на macOS без Xcode-проекта

Актуальный Safari умеет временно подключать папку Web Extension:

1. В Safari откройте Settings → Advanced и включите показ функций для web-разработчиков.
2. Откройте Settings → Developer и включите Allow unsigned extensions.
3. Выберите добавление временного расширения и укажите папку `/Users/mac/Documents/dev/chat-gpt-tools/Extension`.
4. Включите ChatGPT Tools в Settings → Extensions, откройте `https://chatgpt.com` и разрешите доступ к сайту.

Разрешение unsigned extensions сбрасывается после выхода из Safari. Этот путь подходит только для macOS-разработки; для iOS/iPadOS и распространения нужен контейнер Xcode.

Источник: [Running your Safari web extension](https://developer.apple.com/documentation/safariservices/running-your-safari-web-extension).

## Создание Xcode-проекта

Сейчас на машине выбраны только Apple Command Line Tools, в которых упаковщика Safari нет. После установки полной версии Xcode:

```sh
sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
cd /Users/mac/Documents/dev/chat-gpt-tools
./package-safari.sh com.yourcompany.chatgpttools
```

Первый аргумент — ваш уникальный bundle identifier. Не публикуйте вариант `com.example...`. По умолчанию проект создаётся в `SafariApp/`. Дополнительные аргументы:

```sh
./package-safari.sh com.yourcompany.chatgpttools /path/to/output macos
./package-safari.sh com.yourcompany.chatgpttools /path/to/output ios
```

Значение платформы может быть `all`, `macos` или `ios`.

Скрипт не перезаписывает существующий проект. Упаковщик оставляет ссылку на `Extension/`, поэтому изменения web-ресурсов подхватываются Xcode без повторного копирования.

Перед публикацией оставьте в нативном приложении-контейнере понятный экран помощи: что делает расширение, как его включить, какие сайты оно читает и что данные остаются на устройстве. App Review ожидает от приложения с extension полезную host-app функциональность, а для targets также потребуются полноценные macOS/iOS AppIcon assets.

## Первый ручной тест

1. Откройте сгенерированный `.xcodeproj`.
2. Выберите свою команду подписи для приложения и extension target.
3. Соберите и запустите приложение-контейнер.
4. В Safari включите расширение в Settings → Extensions.
5. Откройте `https://chatgpt.com`, нажмите кнопку расширения и разрешите доступ к сайту.
6. Откройте длинный чат, установите небольшой лимит и перезагрузите страницу.
7. Проверьте переключение оптимизатора, компактные счётчики `shown`/`hidden` внизу страницы и сворачивание длинных пользовательских сообщений.
8. Нажмите `Export Conversation`, выберите сообщения и проверьте локальные форматы; для PDF подтвердите системное окно печати.

Для iPhone/iPad разрешение управляется в Settings → Safari → Extensions. Private Browsing и отдельные профили Safari могут потребовать отдельного включения расширения.

## Ограничения проверки

Автоматически проверяются манифест, все ссылки на ресурсы, CSP, синтаксис JavaScript, миграция настроек, алгоритм обрезки, активная ветка экспорта, reasoning, источники и сериализация четырёх локальных форматов. Реальные селекторы DOM и формат внутреннего `/backend-api/conversation/...` зависят от текущей реализации ChatGPT, поэтому Safari-проверку нужно повторять после заметных обновлений сайта.

## Последняя проверка в Safari

Версия 2.0.2 проверена 21 августа 2026 года в Safari с реальной авторизованной сесией ChatGPT. Ручной ввод `7` синхронизировал ползунок и дал `7 shown / 5 hidden`; без флага значение `25` ограничилось до `20`, а с `Extended range` сохранилось как `25`. Итоговое состояние возвращено к `10 shown / 2 hidden`. Экспортёр открылся из основного popup, показал все 12 исходных сообщений при 2 скрытых, успешно перешёл в 11/12 и обратно при индивидуальном выборе, а панель параметров раскрылась с прежними настройками. Кнопок раскрытия сообщений и `Re-compact Current Chat` в DOM нет.
